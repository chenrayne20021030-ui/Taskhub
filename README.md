# Taskhub — Microsoft Edge 日历任务看板

**Taskhub** 是一款以日历为核心的轻量级个人任务管理工具，作为 Microsoft Edge 的 Manifest V3 扩展运行。你可以在月历上安排单日或跨日期任务，通过分类颜色与 ⭐ 重要标记区分事项，创建重复日程，并在 Edge 侧边栏中快速处理当天待办。

**当前版本：v1.7.0** · **平台：Microsoft Edge** · **仓库：Public · No license**

## 功能概览

| 功能 | 说明 |
| --- | --- |
| **月历与列表视图** | 在月历中直观查看日程，或切换列表集中管理任务。 |
| **中英双语界面** | 在中文和英文界面之间切换；用户自己输入的任务名、分类名保持原文。 |
| **自定义分类与颜色** | 自由创建分类，使用鲜亮预设色卡快速选择颜色，也支持自定义调色盘。 |
| **单日与跨日期任务** | 设置开始、结束日期；跨天任务以连续色条显示在日历中。点击日期可快速新建当天任务。 |
| **重复日程** | 在新建任务窗口中开启「重复」，支持按天、周、月或自定义间隔生成任务；每次日程可以独立处理。 |
| **Excel 批量导入** | 根据固定 `.xlsx` 模板录入普通或重复任务，导入前预览检查，自动跳过重复记录。 |
| **三种任务状态** | 区分待办、已完成及手动标记的「未完成」。过期待办会顺延显示到今天，不修改原始日期。 |
| **⭐ 重要标记** | 在创建或编辑时标记重要任务，也可以在任务列表、侧边栏中快捷切换星标。 |
| **待完成任务统计** | 按当前查看月份统计待办数量，排除已完成和手动标记未完成的任务。 |
| **每日多次提醒** | 自定义一天中的多个提醒时刻，通过 Edge 系统通知提示今日未完成事项。 |
| **多种打开方式** | 支持 Edge 原生侧边栏、完整日历看板及独立浏览器窗口。 |
| **本地保存** | 使用浏览器扩展存储保存任务、分类和提醒设置，无须登录云端账户。 |

## 快速开始

Taskhub 当前通过 **Edge 开发人员模式**加载，不需要安装 Node.js，也不需要执行构建命令。

1. 下载仓库源码 ZIP 并解压，或使用 Git 克隆仓库。
2. 在 Microsoft Edge 地址栏打开 `edge://extensions/`。
3. 开启 **开发人员模式（Developer mode）**。
4. 点击 **加载解压缩的扩展（Load unpacked）**。
5. 选择直接包含 `manifest.json` 的项目根目录（不要选择它的上一级目录）。
6. 在 Edge 工具栏固定 Taskhub 图标。点击图标即可打开 **侧边栏**。

侧边栏中可以进入完整日历看板，也可以打开独立窗口。安装或升级有问题时，请参阅 [详细安装指南](docs/INSTALL.md)。

## 使用指南

### 1. 创建和管理日程

在完整看板中点击 **「＋ 新建」**，或直接点击日历里的日期，即可填写任务名称、日期、分类和状态。

- **普通任务**：设置开始日期和结束日期；相同日期表示单日任务，日期不同表示跨天任务。
- **分类颜色**：可以直接使用预设色卡，也可以为分类选择自定义颜色。
- **重要任务**：打开 **「⭐ 重要任务」** 开关；星标不改变原本的分类颜色和任务状态。
- **日历操作**：点击空白日期区域快速新增；点击已有日程可编辑该项任务。

### 2. 待办、已完成与未完成

Taskhub 将任务状态与重要程度分开管理。任务可以是普通待办，也可以同时带有 ⭐ 重要标记。

| 状态 | 在日历中的表现 | 处理规则 |
| --- | --- | --- |
| **待办** | 保留分类颜色 | 尚未完成，仍计入待完成任务数。 |
| **自动顺延** | 浅橙色并显示顺延提示 | 任务已超过结束日期、仍是待办时，会显示在今天；**不复制任务，也不改写原始日期**。 |
| **已完成** | 灰色、勾选标志及划线效果 | 不再计入待完成任务数。 |
| **手动标记「未完成」** | 浅红色并显示「未完成」 | 保留在原定日期、停止自动顺延，也不计入待完成任务数。 |

「已完成」与手动「未完成」互斥，可以在之后重新修改状态。⭐ 重要标记与这些状态独立。

### 3. 创建重复日程

新建任务时开启 **「重复日程」**，即可选择：

- 重复单位：每天、每周或每月。
- 重复间隔：例如每 2 天、每 2 周、每 1 个月。
- 起始日期与截止日期：控制生成日程的时间范围。
- 每周重复日期：例如每周一、周三、周五。

例如：将「英语听力」设为 **每天重复**，再设置一个月的日期跨度，即可快速生成该时间段内的多次任务。

> 当前版本会根据设置的时间跨度**预先生成各次日程记录**。每次日程可以分别勾选完成、编辑或删除；编辑其中一次，不会自动修改同组其他日程。

### 4. Excel 批量导入

仓库根目录提供 [`Taskhub_Import_Template.xlsx`](Taskhub_Import_Template.xlsx)，适合一次性安排大量日程。

1. 打开模板，在第一个工作表 **`Tasks`** 中填写任务。
2. 按模板保留原有表头；核心字段包括 `Task Name`、`Start Date`、`End Date`、`Category`、`Completed`、`Repeat Unit`、`Repeat Interval` 和 `Weekdays`。
3. 日期推荐使用 `YYYY-MM-DD`（如 `2026-11-05`）；不重复的任务将 `Repeat Unit` 填为 `none`。
4. 在完整看板中打开 **Excel 导入**，选择填写后的 `.xlsx` 文件。
5. 检查导入预览、错误提示和重复项数量，确认后再正式导入。

导入支持按规则生成重复日程；未存在的分类可自动创建，识别为重复的任务记录会跳过。模板第二个工作表包含填写说明。

### 5. 设置每日提醒

在完整看板中打开 **「提醒」**，开启桌面通知后，可以添加多个每日提醒时间。提醒会根据当前任务完成状态汇总今日待办，并提示需要留意的未完成事项；重要任务可优先出现在提醒内容中。

提醒依赖 Edge 的扩展定时与系统通知能力。**Edge 需要运行，系统也应允许其发送通知**。电脑关机、休眠或开启免打扰时，提醒可能延迟或不显示；它不能保证像手机闹钟一样在所有情况下准点响起。可以先使用设置界面的 **测试通知** 检查权限。

### 6. 侧边栏、完整看板与独立窗口

- **Edge 侧边栏**：在浏览网页时查看紧凑月历与今日待办，快捷新增和修改任务状态。
- **完整看板**：适合查看整月安排、管理分类、批量导入或设置提醒。
- **独立窗口**：将 Taskhub 作为单独窗口打开，便于多任务办公。

这些界面共享同一扩展数据；修改任务后，其他打开的 Taskhub 界面可读取更新后的内容。

## 数据存储与隐私

Taskhub 使用 `chrome.storage.local` 在当前 Edge 浏览器配置文件中保存任务、分类、状态与提醒设置。**当前没有账号系统、云端备份或跨设备自动同步。** 上传项目源代码到 GitHub 不会自动上传你的个人日程。

请注意：

- 卸载扩展、清理浏览器配置文件或更换设备，都可能使本地任务数据不可用。
- 在大版本更新、迁移电脑或清理浏览器之前，建议使用应用内的备份功能保存个人数据。
- 不要将包含私人任务的 JSON 备份、已填写的 Excel 或其他个人信息提交到公开 GitHub 仓库。

详见 [数据存储与扩展权限说明](docs/DATA_AND_PRIVACY.md)。

## 版本更新与数据保留

如果你已经在 Edge 中安装了 Taskhub，请尽量**原目录覆盖升级**，不要通过卸载重装来更新：

1. 如有重要任务，先在旧版本中导出备份。
2. 将新版文件覆盖到之前加载的扩展目录，保持 `manifest.json` 位于根目录。
3. 打开 `edge://extensions/`，找到 Taskhub，点击 **重新加载（Reload）**。
4. 检查月历、已有任务、分类颜色、提醒设置与侧边栏是否正常。

Taskhub 会尽可能保持旧版数据结构兼容，但浏览器本地数据仍应由使用者妥善备份。具体操作见 [安装与更新指南](docs/INSTALL.md)。
