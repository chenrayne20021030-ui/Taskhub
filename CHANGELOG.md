# Changelog

Notable changes to Taskhub are documented here.

## [1.7.0] - 2026-11-04

- Added an important-task ⭐ flag, independent of task completion status.
- Displayed important markers in the calendar, task list, and Edge side panel.
- Added quick star toggles in task lists and the side panel.
- Replaced the completion percentage card with a pending-task count.
- Excluded completed and manually marked incomplete tasks from the pending count.

## [1.6.0]

- Added automatic carryover for overdue pending tasks without duplicating records or changing original dates.
- Added a manually marked incomplete state, visually distinct from pending and completed.
- Added an Edge native side panel and a separate browser window entry point.
- Kept the full dashboard, side panel, and separate window in sync through extension storage.

## [1.5.0]

- Unified ordinary and recurring schedule creation in one dialog.
- Added a repeat toggle that reveals recurrence settings only when needed.
- Kept individual occurrences independently editable.

## [1.4.0]

- Added multiple daily reminder times.
- Added Edge system notifications summarizing today's unfinished tasks.

## [1.3.0]

- Added recurring schedules with daily, weekly, monthly, and custom intervals.
- Added Excel bulk import with a fixed template and preview.

## [1.2.x]

- Added bright preset category color swatches and custom color selection.
- Fixed calendar rendering and date compatibility issues.

## [1.1.0]

- Added Chinese/English interface switching.
- Added click-a-day quick creation from the calendar.

## [1.0.0]

- Initial calendar planner with task creation, categories, color coding, and completion tracking.
